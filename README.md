# Online-Grocery-Store-Sales-Analysis-Power-BI-Dashboard-
**Project Overview**

This project is an interactive Power BI dashboard created using an Excel dataset from an online grocery store business. The dashboard focuses on analyzing sales performance, customer ratings, order trends, shop performance, and product category insights across different city and shop types.

The main objective of this project was to practice data cleaning, DAX measures, using parameter, and interactive reporting using Power BI.

**Dataset Information**

The dataset contains transactional and shop-related information with columns such as:

Item Code <br>
Item Category <br>
Shop Code <br>
City Type <br>
Shop Size <br>
Shop Type <br>
Item Weight <br>
Sales <br>
Rating <br>
Shop Opening Year <br>

The dataset was imported from Excel into Power BI. <br>

**KPIs Created**

The dashboard includes several important KPI cards:

Total Sales <br>
Total Orders / Transactions <br>
Average Sales <br>
Average Rating <br>
Total 5-Star Ratings

These KPIs provide a quick overview of overall business performance.

**DAX Measures Used**

Custom DAX measures were created to calculate:

Total Sales<br>
Total Orders<br>
Average Sales<br>
Average Rating<br>
Total 5-Star Ratings<br>

A dynamic measure was also created using Power BI field parameters to allow users to switch between different metrics interactively.
